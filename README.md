# figure-skate-database-3d
Illustrative Blender and GLB progress archive for Beijing 2022 men's singles. It contains no Beijing 2022 competition motion capture.

The [current 2A preview](player.html?id=2A) uses the third revision of the FS-Jump3D C07 training trial. See the [three-round side view comparison](2a-iterations.html) and [source and license notice](THIRD_PARTY_NOTICES.md#double-axel-database-rebuild-2a-fs).
